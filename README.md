追記　ブランチモデル「Gitフロー」での作業する手順について
（base branchの名前をdevelop branchに変更しました）
mainをそのまま編集するわけにはいかないので、編集する作業場を分ける、といった考え方です。
mainはいつでもリリース可能にして、developが全員の編集内容をmerge（合流）させる場所とします。
皆さんがこれから編集作業するときには、developbranchをbaseとしてbranchを新しく作成して、そのうえで編集作業を行ってください。
その後、その自分用編集branchをdevelop branchにmergeすることで、全員の編集内容をまとめていくって寸法です。
ので、develop元でbranchを作って作業するようにしてください。（brunch名に、誰が何を編集しているのかわかるようにしてくださいね。）
